## 🚀 How to Run & View Locally

### Option 1: Double Click
Simply double-click `d:\Nilanjan\Dreams\cs-tuition-website\index.html` in Windows File Explorer.

```powershell

# Or:

```
Then visit `http://localhost:3000` in your browser.
